## 👋 About Me

- **End-to-End 프로덕트 빌더**  
  기획 → 설계 → 개발 → 배포 → 운영까지 한 사람이 끝까지 책임지는 걸 선호합니다.
- **비즈니스 임팩트를 보는 개발자**  
  기능 구현보다, 가입률·전환율·운영 효율처럼 **숫자로 말할 수 있는 결과**에 관심이 많습니다.
- **실무 × 해커톤 × 사이드 프로젝트**  
  회사에서의 1인 E2E, 해커톤, 그리고 개인 SaaS까지, 여러 문맥에서 제품을 만들어 보고 있습니다.

> “지금까지 만든 것들은, 내가 만들고 싶은 제품들을 향한 중간 기록일 뿐입니다.”

## 🌟 Core Values

<div align="center">

| Value | 설명 |
| --- | --- |
| **End-to-End** | 기획·개발·배포·운영까지, 한 번 맡으면 끝까지 가져가는 습관 |

| **가치 설계 우선** | “무엇을 만들지”보다 “어떤 문제·가치인지”를 먼저 정의하고 설계 |

### 1. PlanFlow – AI 기반 프로젝트 플로우 자동화 (Hackathon · Solo)

- **Stack**: React, Node.js, OpenAI API  
- **What**  
  - 프로젝트·태스크를 입력하면, AI가 **우선순위와 일정**을 추천해 주는 플로우 자동화 SaaS
- **Role**  
  - OpenAI × 조코딩 해커톤에서 **기획부터 개발·제출까지 1인 수행**
- **Highlights**
  - 태스크 구조를 LLM으로 분석해, 일정·우선순위를 자동 계산하는 로직 설계
  - 기능 나열이 아닌, “어떤 문제를 풀고 어떤 가치를 줄지”를 먼저 정의한 뒤 구현

### 2. SellerKit – 쿠팡 셀러용 광고·데이터 분석 SaaS (Company · Solo E2E)

- **Stack**: Vue 3, Spring Boot 3.2, Redis, AWS, Chrome Extension  
- **What**  
  - 쿠팡 셀러가 광고·매출·키워드 데이터를 한 번에 보는 **올인원 분석 대시보드 & Extension 3종**
- **Role**
  - **1인 풀스택**: 설계 → 백엔드 → 프런트 → 인프라 → Chrome Extension까지 E2E
- **Highlights**
  - 마진 계산, 광고 효율 분석, 키워드 추적 등 **실제 셀러 문제에 바로 닿는 기능** 설계
  - 광고·키워드 데이터 수집 자동화로, 기존 수작업 대비 **분석 시간 ~80% 단축**

### 3. OneStack – IT 전문가 매칭 & 협업 플랫폼 (Team · Lead)

- **Stack**: Java, Spring Boot, WebSocket, AWS, Docker  
- **What**
  - IT 전문가와 프로젝트를 매칭하고, 실시간 채팅/화상회의로 협업하는 **커뮤니티 플랫폼**
- **Role**
  - 팀장으로서 요구사항 정의, 아키텍처 설계, 핵심 기능 개발, 배포까지 리딩
- **Highlights**
  - 실시간 채팅(WebSocket), 프로젝트 매칭 플로우, 팀/프로젝트 관리 기능 설계
  - 인프라 구성 및 CI/CD 파이프라인 구축으로 **릴리즈 부담 최소화**

## 💭 Philosophy

> **“확신은 가장 우유부단한 사고방식.”**  
>  
> 그래서 저는,  
> - 빠른 확신보다 **꾸준한 검증과 개선**을 믿습니다.
